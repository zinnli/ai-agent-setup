# feature-plan 체크리스트

## 요구사항
- [ ] 기능의 목적을 한 문장으로 설명할 수 있다.
- [ ] 완료 조건이 명확하다.
- [ ] 모호한 요구사항을 질문으로 확인했다.

## 현재 구조
- [ ] 관련 컴포넌트·훅·상태·API·타입을 확인했다.
- [ ] 재사용 가능한 기존 코드·패턴을 확인했다.
- [ ] 유사 기능의 기존 구현을 참고했다.

## 영향 범위
- [ ] 변경·추가할 파일을 나열했다.
- [ ] 상태 관리·API 계약·타입 변경의 파급 효과를 확인했다.
- [ ] 새 의존성의 필요성과 대안을 검토했다.

## 계획
- [ ] 작업을 검증 가능한 단계로 나눴다.
- [ ] 각 단계의 검증 방법을 정했다.
- [ ] 로딩·오류·빈 상태를 목록화했다.
- [ ] 리스크와 미확정 사항을 명시했다.
