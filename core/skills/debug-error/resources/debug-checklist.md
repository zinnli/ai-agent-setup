# debug-error 체크리스트

## 파악
- [ ] 전체 에러 메시지·스택 트레이스를 확인했다.
- [ ] 발생 조건과 기대/실제 동작 차이를 정리했다.

## 재현
- [ ] 최소 조건으로 재현했다.
- [ ] 재현 절차를 기록했다.

## 원인
- [ ] 스택의 최초 발생 지점부터 역추적했다.
- [ ] 최근 변경이 원인인지 확인했다.
- [ ] 가설을 로그·값으로 검증했다(추측으로 단정하지 않음).

## 수정
- [ ] 증상이 아닌 근본 원인을 고쳤다.
- [ ] 같은 원인의 다른 케이스를 점검했다.
- [ ] 범위를 넘어선 변경이 없다.

## 검증·재발 방지
- [ ] 재현 절차로 문제 해결을 확인했다.
- [ ] 타입·린트·테스트를 실행했다.
- [ ] 회귀 테스트를 추가했다(가능한 경우).
